### AI Resume Screener | AI-Powered Recruitment Platform

An intelligent recruitment platform designed to streamline the initial hiring process by automating resume analysis and candidate-job matching. The system processes candidate resumes, evaluates their relevance against job descriptions, generates match scores, and ranks applicants with AI-generated explanations to support faster, more consistent screening.

**Key Features**
- **Resume Analysis:** Upload and process multiple candidate resumes in PDF format.
- **Intelligent Matching:** Compare candidate skills and qualifications against job requirements.
- **AI-Powered Scoring:** Generate candidate relevance scores and rank applicants based on job alignment.
- **Explainable Results:** Provide insights into candidate matches to support informed screening.
- **Job & Data Management:** Manage job descriptions, resume records, and matching results using persistent database storage.
- **REST API:** Backend services built with FastAPI for efficient application communication.

**Tech Stack:** Python · FastAPI · React · PostgreSQL · Neon · Gemini API
